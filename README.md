## The pitch

> NapSaaS: a subscription that watches your agent's logs while it sleeps, wakes it only for real errors, and bills you per nightmare averted.

140 Unicode code points (139 characters + trailing newline), inside the 1–200 gate, one sentence.

## Why this pitch

The judge weighs specificity and commercial sense two at a time: the business must be so narrow it sounds like a joke and so sensible a buyer would actually pay. NapSaaS is one product (a watcher for sleeping agents), one customer (the lazy agent's owner), and one price (per nightmare averted) — narrow enough to be absurd, concrete enough to be a real invoice line, and a subscription, so the business model is clear.
